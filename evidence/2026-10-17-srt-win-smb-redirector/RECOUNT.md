# Re-count of the figures in README.md

`recount.py` reads, per proof-of-concept run, `result.json` (each pass's C1, C2, T and C3 payload records and the
listener log `all_listener_records`, matched to a pass by its `phase`) and the final `run_status=... result=... exit=...`
line of `console.txt`; for the virtual machine also `winver.json`, `security_center.json` and `srt-win-install.json`;
for harness runs 4-7 `listener.jsonl`, `session-extract-U0-U1p-U1.json`, `wfp-before.json`, `wfp-after.json` and
`verdict.json` (including, per run, the WebDAV states U2a to U2pt that ran before the SMB fixture stopped the batch,
the order in which each state family first reached the listener, the fx-b verdict, and the test-account SMB states
U1t and U1pt); for runs 8-9 `listener.jsonl`, `counts.json` and `verdict.json`; the three
`owner-attribution-20261017/repeat-*.txt` transcripts; and every file under `poc/`, which it hashes. It prints
`name = value` figures. Every figure is recomputed from those records. The records' own summary fields are printed
beside it under a `record.` name and never used in its place. Aggregates: `host.v1-3` is the nine main-host runs of
versions 1-3 (its `derivation` line names them and their passes), `host.v1-4` adds `v4-run-1`; `vm.all` is the two
virtual-machine runs. Toggle runs enter no aggregate.

    python recount.py <folder>                    # print the figures
    python recount.py <folderA> <folderB>         # print both and the differences; exit 1 on any difference

`poc-runs/v3-vm-suite-absent/`. The script reads whichever exists and prints its figures under `vm.`; that is the only
path it maps.
