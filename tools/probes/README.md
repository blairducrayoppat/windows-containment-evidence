# Probe scripts

Each script that produced evidence here, with what it measures, how to run it, what it writes and what it does not
measure. Scripts that ran from inside an evidence folder stay there, beside their run records, so a run and the bytes
that produced it are never separated; this file indexes them. No script imports anything from outside this repository
apart from the platform tools it drives (PowerShell, WSL, nono, srt-win, the Rust toolchain for the harness).

| Script | Measures | How to run | Writes | Does not measure |
|---|---|---|---|---|
| `tools/probes/nono_9p_failclosed_control.py` | Whether nono's Landlock sandbox on the WSL 9P mount (`/mnt/c`) lets a process do something its own command line does not grant: 30 probes (writes, reads, listings through junctions, symlinks, `..`, case and 8.3 spellings, streams, hard links) in 4 grant configurations | Windows, elevated: `--prepare-windows`; optional `--preflight-windows --fixture <name>`; WSL as root: `--live --fixture <name> --operator agent --out <file>`; Windows: `--cleanup-windows --fixture <name>`. `--self-test` and `--dry-run` change nothing | One JSON result (`--out`), the fixture under `C:\wsl\<fixture>` and its prepare record (removed by `--cleanup-windows`) | Enforcement on any filesystem other than 9P; nono versions other than the one recorded; network policy; another machine or kernel |
| `tools/probes/mxc-proxy-egress/` | With `runtimeConfig.networkProxy` at a loopback proxy: whether `wxc-exec` accepts the policy and, if so, whether direct connects from the container (a second loopback listener, the default gateway, 1.1.1.1:443) are refused while a request through the forwarding proxy works; controls from an unconfined process | `launch.ps1` from an elevated console (hash-checks the probe files against an approved list); `run_probe.py --dry-run-only` changes nothing; `python -I -B self_test.py` changes nothing on the machine but binds the live probe ports 18110, 18111 and 18113, so never run it while a live run may be in progress or pending | Raw records under a folder of your choice (not inside a git tree) | Other builds; non-elevated live runs; an identity-scoped proxy; UDP, ICMP, DNS; host-to-container ingress; the WFP filter list of the container |
| `evidence/2026-10-05-wfp-sid-block/wfp-spike/wfp-coder-egress-spike.ps1` | Whether a raw WFP block filter keyed to one account's SID stops that account's outbound connects while a third-party security product owns filtering | Elevated Windows PowerShell 5.1; `-SelfTest` changes nothing; see that folder's `README.md` for the live order | `result-<stamp>.json`; dynamic-session WFP objects that vanish when the session ends | Persistence; IPv6 beyond the filters listed; other products |
| `evidence/2026-10-05-wfp-sid-block/confined-model-spike/{as-run,post-run-hardened}/` | A restricted, non-interactive batch account: file access to the operator's secrets and outside paths, and loading a model on the GPU through OpenVINO GenAI, with and without the WFP block | `spike-provision.ps1 -Apply`, `spike-run-test.ps1`, `spike-wfp.ps1`, `spike-cleanup.ps1` (each with a self-test or dry run); details in each folder's `README.md` | Run JSON under `runs/`; a throwaway account, ACLs, a scheduled task (removed by the cleanup script) | Another driver or model; the product's own model server; speed |
| `evidence/2026-10-05-wfp-sid-block/arm1-permit/scripts/`, `arm2-hold/scripts/`, `arm3-persist/scripts/` | Arm 1: a loopback permit beside the block; arm 2: a two-hour hold; arm 3: a persistent filter set, added, checked and removed, and its survival across one restart | Each arm's `scripts/README.md` gives the order; the self-tests (`-SelfTest`, `-DryRun`) change nothing; `arm2-hold/selftest/` and `arm3-persist/selftest/` hold self-test records | Run JSON under each arm's `runs/` | See the "Limits" section of `account-level-containment-evidence.md` |
| `evidence/2026-10-13-nep0005-halfset/scripts/spike-nep5-*.ps1` | The half-set matrix: which WFP states (one block missing, permits missing, a stale SID, an extra permit) block or open the test account, and what each state reads as | `scripts/README.md`; offline self-tests use a fake engine | Run JSON under `runs/`; WFP objects in three named test sublayers only, removed by the run | Real IPv6 or internet egress (claim C21) |
| `evidence/2026-10-13-nep0005-halfset/harness/halfset.rs` | The engine-side harness the matrix drives (adds, enumerates and deletes filters in the test sublayers) | Built with Cargo against the pinned srt-win source named in `SPEC.md`; `harness/tests/refusals.ps1` checks its refusal paths | JSON on stdout, collected into the run records | Anything outside the three test sublayers |
| `evidence/2026-10-13-nep0005-halfset/srtcli/srtcli-halfset.ps1` | srt-win's own CLI (`install`, `wfp status`, `wfp verify`, `uninstall`) on each half-set, unpatched and with the candidate fixes in `srtcli/fix/` | `-SelfTest`; live use per `scripts/README.md` and `runs/AS_RUN.md` | Run JSON and a summary (`Export-SrtcliSummary.ps1`) | Builds other than the two recorded |
